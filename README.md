# 🚀 Kaden & Adelynn Space Adventures

A modern triangle ship space shooter game built with React, TypeScript, and enhanced visual effects.

## ✨ Features

### 🎮 Core Gameplay
- **Triangle Ship Designs**: Unique ships for Kaden (blue) and Adelynn (pink)
- **Enhanced Shooting System**: All ships can shoot with different bullet types
- **Multiple Collectibles**: Health, shield, score, power, speed, and ammo pickups
- **Enemy Variety**: 4 different enemy types (basic, fast, heavy, zigzag)
- **Boss Battles**: Destroyer and Battleship bosses with special attacks

### 🎨 Visual Design
- **Orbitron Font**: Futuristic sci-fi typography
- **Animated Starfield**: Multi-layered stars with twinkling effects
- **Glowing Effects**: Enhanced UI with colored shadows and glow
- **Smooth Animations**: Professional hover effects and transitions
- **Health Bar**: Color-coded health display with visual feedback

### 📱 Mobile Support
- **Touch Controls**: Optimized for mobile devices
- **Responsive Design**: Works on all screen sizes
- **iOS Safari**: Special optimizations for iPhone/iPad
- **PWA Support**: Service worker for offline functionality

### 🎯 Game Features
- **Character Selection**: Choose between Kaden and Adelynn
- **Pause/Resume**: ESC key or button to pause
- **Game Over System**: Restart or return to menu
- **Scoring System**: Points for destroying enemies and bosses
- **Level Progression**: Bosses spawn based on score

## 🚀 Quick Start

### Prerequisites
- Node.js 16+ 
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/ronb12/kaden-adelynn-space-adventures.git
cd kaden-adelynn-space-adventures

# Install dependencies
npm install

# Start development server
npm start
```

### Build & Deploy
```bash
# Build for production
npm run build

# Deploy to Firebase
firebase deploy --only hosting
```

## 🎮 Controls

### Desktop
- **Arrow Keys / WASD**: Move ship
- **Space**: Shoot
- **ESC**: Pause/Resume

### Mobile
- **Touch Controls**: Virtual joystick and shoot button
- **Swipe**: Move ship
- **Tap**: Shoot
